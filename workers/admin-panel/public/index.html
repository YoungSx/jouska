用恢复令牌重置密码

先在 D1 里开一个窗口（30 分钟后自动失效、用一次即废）：

npx wrangler d1 execute jouska-admin --remote --command "
  INSERT INTO settings (key, value) VALUES ('password_reset',
    json_object('token','换成一段够长的随机串',
                'expiresAt', unixepoch() + 1800))
  ON CONFLICT (key) DO UPDATE SET value = excluded.value;"
